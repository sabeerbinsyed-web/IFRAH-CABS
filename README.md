# IFRAH CABS Android App

This is a lightweight Android WebView app that opens the live IFRAH CABS website:
https://ifrahcabs.in

It is designed for phone-only APK building through GitHub Actions.

## Build
1. Upload this project to a GitHub repository.
2. Add the Android platform files using `flutter create .` in a cloud development environment, OR use the provided GitHub Actions workflow after the Android folder is present.
3. Run the workflow.
4. Download the APK artifact.

The website itself already handles Firebase bookings and WhatsApp booking.
