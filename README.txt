SHOREWAY / IFRAH CABS CAB BOOKING WEBSITE
===========================================
Files:
- index.html
- style.css
- script.js

How to use:
1. Unzip the folder.
2. Open index.html in a browser to test.
3. Upload all three files to any static website host.
4. WhatsApp bookings go to 8940694977.

Important:
- The fare shown on the site is indicative.
- Replace the fare table and service details whenever your prices change.
- For live online payments, admin dashboard, database bookings, Google Maps and driver assignment, a backend/database is required.
